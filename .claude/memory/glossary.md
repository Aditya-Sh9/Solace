# SOLACE — Glossary

Domain terms used throughout the codebase.

- **Check-in** — A daily wellness log entry (mood, sleep, etc.)
- **Insight** — AI-generated finding about the user's patterns
- **Deficiency Flag** — A signal from the rule engine suggesting a possible nutrient gap
- **Pattern Model** — The user-specific scikit-learn model
- **Phase** — A development phase (Phase 0 through 7) OR a menstrual cycle phase
- **Journal Entry** — Encrypted private writing (never analyzed)
- **Rule Engine** — Deterministic symptom-to-flag mapping
- **Mood Score** — 1–6 scale, illustrated faces
- **Streak** — Consecutive days of check-ins
- **Soul** — The intangible warmth and humanity of the UI (yes, we say "soul" in this project)
